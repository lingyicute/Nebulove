### 🌠「Nebulove」？

「Nebulove」是星光与心事相拥时诞生的名字：
星云揉碎深蓝夜幕里银河的柔光，把爱意藏进圆润的转角。

就让它们替我带去比银河系更漫长的想念，
以及所有还没来得及说出口的喜欢。
